# KriturKreature

A Minecraft mod that adds a creature called Kritur which is a mascot / character based on a Twitch streamer Kritur's -Kritur emotes.

## Structure

- `1.20.1/` — Forge 1.20.1 mod project

## Building

```bash
cd 1.20.1
./gradlew build
```

The built JAR will be in `1.20.1/build/libs/`.
